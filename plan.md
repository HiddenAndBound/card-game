# Card based Roguelite game


## Summary

A roguelike card battling game like Slay the Spire, Inscryption or Monster Train. The game's main twist is that the game master is a small llm that has the ability to give truly dynamic and random dialogue and commentary along with influencing the game state meaningfully.

Current stack: Rust with Bevy.
